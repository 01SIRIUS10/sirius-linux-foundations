## 📖 About This Repo

I'm a computer science student building my way toward **Web Application
Penetration Testing**, and eventually **AI Red Teaming**. Before touching
a single web app vulnerability, I needed to be genuinely comfortable in
a Linux terminal — not memorizing commands, but understanding them.

This repo is that process, documented honestly:

- The concepts, in my own words
- The commands I actually ran
- The mistakes I actually made
- A full wargame (OverTheWire Bandit) solved without a single walkthrough

Nothing here is copy-pasted from a tutorial. If something is wrong,
it's because I understood it wrong — not because I copied it wrong.
